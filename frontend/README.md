# NexusLMS Frontend – React 19 + Vite + Tailwind CSS 4

Enterprise SaaS GUI for the Learning Management System with Role-Based Dashboards (Admin, Instructor, Student), Recharts analytics, AOS scroll animations, Framer Motion interactions, and full FastAPI backend integration.

## Quick Start

```bash
cp .env.example .env
npm install --legacy-peer-deps
npm run dev
```
